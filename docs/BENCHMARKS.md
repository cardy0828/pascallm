## llama.cppとの比較

[Gemma 4 12BのMTP比較](GEMMA4_LLAMA_MTP_COMPARISON.md)に、2026-11-17の測定条件、通常/MTPの速度、入力処理時間、出力差と制約を掲載しています。

## 開発時測定の要約

GTX 1080 Ti、Linux、Gemma4 12B PQ4、FP16 KV、固定3候補での開発時測定です。
各条件1回の値を含み、性能保証ではありません。公開版での再測定ではありません。

| 条件 | 通常 | MTP |
| --- | ---: | ---: |
| temperature 0.7・ペナルティ付き本文 | 45.86 tok/s | 65.60 tok/s |
| ツール required・temperature 0.7 | 29.79 tok/s | 51.69 tok/s |
| JSON Schema・temperature 0.7 | 27.87 tok/s | 45.61 tok/s |
| temperature 1.5・全語彙 | 16.18 tok/s | 15.95 tok/s |

最大128生成。decodeのみで、入力処理は含みません。高温・全語彙では改善しませんでした。
K FP32 / V FP16は長文の診断KLが改善しましたが、正答率の改善を確認できず速度低下もあるため、FP16を既定にしています。

ホストprefix保持（1024 MiB・8保存点）のAPI測定:

| 条件 | 無効 | 有効 |
| --- | ---: | ---: |
| 会話A 初回（567 tokens） | 980.25 ms | 1161.78 ms |
| A→B→A再訪 | 977.49 ms | 121.88 ms |
| 同じsystemの別質問 | 980.37 ms | 757.52 ms |

入力処理にはKV保存・復元を含みます。再訪では有効ですが、初回には保存負荷があります。
開発時にAPI出力一致、FP16/K FP32のKV復元、全logits比較、SSE、ツール、停止・キャンセルを検査しています。
生ログと個別機器の運用情報は公開対象に含めていません。

これらは開発者による内部確認です。第三者向けに資産取得から測定までを完全再現する手順は未整備です。
